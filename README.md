# Nigerian Food Ordering System

A terminal-based Nigerian food ordering system built with Python.

## Features

* Choose a food category
* View available food items
* Place food orders
* Validate orders
* Accept uppercase and lowercase input
* Display food prices
* Place multiple orders

## Technologies

* Python 3

## How to Run

Clone the repository, open the project folder, and run:

```bash
python3 menu.py
```

## Example

```text
What would you like to order? drinks

Coke
Water
Juice

What would you like to order? coke

You ordered Coke ₦500!
```
